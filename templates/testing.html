Apa itu Pengujian Black-Box pada Sistem Ini?

Pengujian Black-Box (Tahap 5) memposisikan penguji sebagai pengguna akhir yang hanya berinteraksi dengan antarmuka sistem (form upload, tombol pengujian sampel, API eksternal) tanpa melihat kode internal model. Uji ini memverifikasi bahwa:

  • • Citra deepfake valid menghasilkan label DEEPFAKE dan berkas heatmap.
  • • Citra asli valid menghasilkan label REAL dengan gradien dingin.
  • • Berkas non-gambar ditolak secara aman untuk mencegah exploit.
  • • REST API mengembalikan JSON berstruktur seragam.
Eksekusi Mandiri melalui Terminal CLI

Pengujian ini juga dapat dijalankan langsung melalui Command Line Interface (CLI) otomatis untuk kebutuhan integrasi berkelanjutan (CI/CD):

python test_blackbox.py

Menghasilkan kode exit 0 saat seluruh test case sukses lolos validasi.
